# backend-lab

백엔드에서 자주 만나는 데이터·성능 문제를 **작게 재현하고, 직접 측정해서, 기록**하는 실험실.

- 실험 하나 = 폴더 하나 (`labs/NNN-topic/`)
- 각 폴더에는 바로 실행되는 코드와 `README.md` (문제 → 실험 → 결과 → 배운 점)
- 가능하면 표준 라이브러리만 사용해서 `python3 main.py` 한 줄로 재현
- 수치는 직접 돌린 값만 적는다. 환경에 따라 달라질 수 있음을 함께 표시
